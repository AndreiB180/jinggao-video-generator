镜稿源码交接版，尚未完成四分钟 / 十分钟 / 一毛钱的整片验收。
开发者请先阅读 README.md、docs/HANDOFF.md 和 CLAUDE_HANDOFF_PROMPT.md。
在源码目录安装依赖、构建前端、下载字体与本地字幕模型后运行 launch.py。
启动后在「设置」里填写阿里云百炼 API Key（文案、看图和千问配音共用这一个 Key），然后在首页粘贴文案或上传音频，点「开始生成」。
成片自动保存到「视频/镜稿成片」文件夹；外挂字幕 SRT 在其中的子文件夹，只在上传平台时使用，播放时不要加载。
API Key 只保存在本机，不在仓库或发行包中提供。
软件自带素材库（assets/footage-index，数万个 B 站视频的画面描述，不含视频本身），首次启动时在后台自动导入，出片时优先从库里找画面；左栏「素材库」可以继续按题材扩充。
