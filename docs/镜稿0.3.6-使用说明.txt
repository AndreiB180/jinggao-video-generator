镜稿 0.3.6（Windows 10/11 64 位）使用说明

这一版改了三件事：
1. 真正用上 NVIDIA 显卡。以前安装包里的视频工具要求显卡驱动 610 以上，驱动旧一点就悄悄全部改用 CPU，所以慢。
   现在换成了只要求驱动 471.41 以上（2021 年以后的驱动都行）的版本：候选画面的解码、缩放、编码和最终合成都交给显卡。
2. 同时做多条不再把电脑占满。转码数量按 CPU 核数封顶，制作进程用「低于正常」优先级运行，
   一边批量出片一边用电脑（浏览器、微信、剪映）不会卡。同时制作最多可选 6 条。
3. 成片在哪一眼能看到。批量队列里每条做好的视频都写着文件名，可以直接「用播放器打开」或「在文件夹中显示」。

一、启动
1. 把 Jinggao-0.3.6-Windows-x64.zip 解压到一个文件夹（建议放在 D 盘之类空间充足的地方，路径里有中文也可以）。
   可以直接解压到旧版文件夹里覆盖，项目和设置都在 data 子文件夹，不会丢。
2. 双击「双击启动镜稿.cmd」。会弹出一个黑色窗口，浏览器自动打开 http://127.0.0.1:8770 。
   旧版还开着的话，新版会自动把它关掉再启动；左下角应显示「v0.3.6 测试版」。
   使用期间不要关这个黑色窗口，关掉它软件就停了；关浏览器不影响后台任务。
3. 启动时会先花几秒测一下显卡，黑色窗口里会有一行结果：
   · 「显卡加速已开启：NVIDIA GeForce RTX 3060（驱动 xxx）……」——正常，转码和合成都走显卡。
   · 「显卡编码已开启……解码仍用 CPU」——显卡能编码，解码那一步没通过，也比全用 CPU 快。
   · 「显卡加速未开启……」——后面会写原因和怎么办。最常见的是驱动太旧：
     到 NVIDIA 官网（https://www.nvidia.cn/drivers/）或 GeForce Experience 更新显卡驱动，装好后重启镜稿。
4. 如果 Windows 提示"已保护你的电脑"，点"更多信息"→"仍要运行"。

二、显卡状态在哪里看
- 左下角「本地工作台」下面一行：显卡加速已开启 / 显卡编码已开启 / 显卡加速未开启（见设置）/ CPU 合成。
- 「设置 → 合成与保存」最上面：显卡型号、驱动版本、同时用几路显卡编码、没开启的原因和建议。
  · 更新驱动或关掉录屏、直播软件后，点「重新检测」，不用重启。
  · 「复制诊断信息」：把显卡、CPU、并发设置和最近 12 条视频每一步用了多久、用的显卡还是 CPU 复制下来，
    直接粘贴到微信发给我们。里面没有 Key，也没有文稿内容。
- 每条视频的成片页也会写：总用时、每一步用时（规划分镜 / 找画面 / 合成），以及画面转码和合成分别有多少是显卡做的。

三、成片保存在哪里、怎么打开
- 做好的 MP4 自动保存到「视频」文件夹下的「镜稿成片」（「视频」文件夹挪到 D 盘等位置也会跟过去）。
  文件名就是视频标题；不带字幕的版本文件名后面加「（无字幕）」；SRT 字幕在其中的「外挂字幕」子文件夹。
- 这个位置现在在四个地方都直接显示完整路径，并且都有「打开文件夹」按钮：
  首页文案框下面、「我的作品」顶部、「批量制作」的制作队列上方、每条视频的成片页。
- 批量制作：队列里做好的每一条都写着「已保存为 xxx.mp4」，右边两个小按钮：
  三角形（播放）图标＝用电脑自带的播放器打开；文件夹带放大镜的图标＝打开文件夹并选中这个视频（鼠标停在图标上会显示文字）。
  点「在这里看成片」可以在软件里播放。
- 「我的作品」：每张卡片下面写着保存的文件名，同样有这两个按钮；点画面进入成片页。
- 成片页：完整路径（可以直接选中复制），「用播放器打开」「在文件夹中显示」「复制路径」。
- 想换保存位置：点任一处的「更改位置」（或「设置 → 合成与保存 → 成片保存位置」旁边的「选择…」），
  会弹出 Windows 选文件夹的窗口（如果没看到，它可能在浏览器窗口后面）。选好以后，之后做好的视频都存到那里。

四、同时做多条视频
- 「批量制作」里「同时制作」可选 1～6 条，会按这台电脑推荐：显卡加速开启时推荐 4 条，只用 CPU 时 2～3 条。
- 不管选几条，所有视频共用同一组名额：显卡同时编码的路数、CPU 同时转码的个数、B 站访问、配音访问都有上限，
  所以条数调高不会把 CPU 占满，只是让更多视频交替使用网络和模型，整批更快做完。
- 想知道选几条最快：拿 6 篇稿子，分别用「同时 3 条」和「同时 4 条」各做一次，看批量队列里的总用时。

五、需要提供的 Key、费用
- 阿里云百炼 API Key（必填），在「设置 → 文稿与视觉模型」填写。配音默认免费，Pixabay 已内置。
- 模型费约 0.02～0.10 元 / 条；这一版没有改变费用。

六、注意
- 每条视频连同候选片段约占 150～500 MB（在软件文件夹的 data 里），批量做 100 条前请确认磁盘有 50 GB 以上空余。
- 素材主要来自 B 站 UP 主视频，没有商用授权，商业发布有版权风险。
- 这一版的显卡部分没能在真正的 N 卡电脑上试过（我们这边没有 Windows + NVIDIA 的机器）。
  软件每一步都有保护：显卡做失败的片段会立刻改用 CPU 重做，同一种显卡方式连续失败 3 次就不再用，最差也和以前一样全用 CPU。
  第一次用请把黑色窗口里显卡那一行、或「复制诊断信息」的内容发给我们，方便确认显卡确实在工作。
