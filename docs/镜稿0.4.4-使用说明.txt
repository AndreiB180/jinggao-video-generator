镜稿 0.4.4（Windows 10/11 64 位）

1. 素材库从 2.8 万个视频扩大到 4.75 万个。
   新增的 1.9 万个，重点补了客户稿子最常用的画面：电视剧、短剧里的夫妻吵架、离婚、婆媳、职场、医院、法庭，
   法治节目和案件纪实，《档案》类人物纪实，国内外新闻现场。每个画面都逐帧写了描述和检索词，找画面更准、重复更少。
   · 第一次打开 0.4.4 时会在后台自动导入新素材库，大约 1 分钟，不影响使用。
2. 社会故事、情感故事的画面更好了。
   以前稿子里的化名（张女士、老周、小李这类）会被当成真人去找“本人画面”，还会拿这些名字去搜索，
   结果搜到不相干的视频反复用，挑好的电视剧片段也会被检查规则拒掉。现在化名按普通人处理，
   讲情节的镜头可以直接用电视剧、短剧片段。
3. 新闻模式现在默认打开。
   时事新闻稿会先找讲同一件事的新闻报道，用报道里讲到这句话之后的现场画面（自动避开主播镜头）。
   客户的三篇新闻稿实测，每篇多用上 1～5 段真新闻画面；这一步和找素材同时进行，基本不多花时间。
   不想用的话：设置 → 素材搜索 → 取消勾选「新闻模式」→ 保存。
4. 修了一个问题：解压到全新文件夹后第一次批量制作，头几条可能直接失败
   （提示 duplicate column name 或 database is locked）。
5. 仍然建议在设置里扫码登录一次 B 站：电视剧、短剧片段登录后才有 720p/1080p。

怎么装：解压覆盖旧版文件夹（项目、设置、一镜登录、远程协助白名单都不会丢），双击启动，左下角显示「v0.4.4 测试版」。
