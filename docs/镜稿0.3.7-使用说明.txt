镜稿 0.3.7（Windows 10/11 64 位）使用说明

这一版改了什么
1. 画面里的乱七八糟的字：软件现在会自己"读"画面上的字。
   · 画面上有"加微信、看私信、需要视频、QQ 号、手机号"之类的，这个视频整段不用，换别的。
   · 原视频（包括电视剧）自带的字幕：能裁掉就裁掉，裁不掉就模糊掉，并且优先换没字幕的画面。
   · 画面中间的大段文字、标题、滚动的字：优先换掉。
   · 这些都是在你电脑上本地识别的，不花钱、不上传。
2. 不再出现画面中间写着人名的"文字卡片"（之前的"潘水苗""Tim"那种）。找不到合适画面时，借用这条视频里已经检查过的画面。
3. 不再一闪而过：每个镜头至少 2 秒左右，太短的会和相邻的合在一起。
4. 音频批量成片（新）：已经用百度一镜等工具配好音的，可以一次导入很多个音频，一个音频做一条视频。
5. 同时做好几条时更省电脑：普通镜头少下载一份备用画面。还有 0.3.6 里的显卡加速、电脑不卡、成片位置一目了然。

一、启动
1. 把 Jinggao-0.3.7-Windows-x64.zip 解压（可以直接解压到旧版文件夹里覆盖，项目和设置都在 data 里，不会丢）。
2. 双击「双击启动镜稿.cmd」。黑色窗口别关；左下角应显示「v0.3.7 测试版」。
3. 启动时黑色窗口会写显卡情况："显卡加速已开启"就是正常；"未开启"后面会写原因（常见是显卡驱动太旧，去 NVIDIA 官网更新即可）。

二、音频批量成片（新）
1. 左边点「批量制作」→ 上面点「音频批量」。
2. 第 1 步：点「选几个音频文件」（在窗口里按 Ctrl+A 全选），或者「选整个文件夹」。
   · MP3、WAV、M4A 都可以。百度一镜导出的 MP4 视频也可以直接放进来，软件只用它的声音，不用先分离音频。
   · 一个文件做一条视频，视频标题就是文件名，所以文件名最好起成标题。
3. 第 2 步一般不用改（同时做几条、横竖屏、清晰度、要不要字幕）。
4. 第 3 步点「开始制作 N 条视频」。会一个一个上传，上传完就可以关掉窗口，后台继续做。
5. 软件会自己听出文字、配画面、按原声加字幕，不会再配一遍音。

三、成片在哪里、怎么看
- 「批量制作」窗口下面的制作队列：做好的每一条都写着"已保存为 xxx.mp4"，旁边三角形图标＝用播放器打开，文件夹图标＝打开文件夹并选中这个视频。
- 「我的作品」、首页、成片页都写着成片文件夹的完整位置，有「打开文件夹」和「更改位置」。
- 成片页还会写这一条：总共用了多久、每一步多久、用的显卡还是 CPU，以及"去字：避开了几个带联系方式的视频、处理了几处字幕"。

四、建议
- 在剪映里另外叠加的数字人头像、口播画面不是镜稿输出的内容。判断镜稿本身的效果时，请直接看「成片文件夹」里的原始 MP4。
- 想知道同时做几条最快：拿 6 篇试「同时 3 条」和「同时 4 条」，看队列里的用时。
- 第一次用请在「设置 → 合成与保存」点「复制诊断信息」发给我们，能看到你电脑上显卡是否生效、每一步花了多久。

五、还做不到的
- 讲公司新闻、抽象概念的文案（比如"董事会""经营范围"），网上没有对应的真实画面，只能配办公室、握手、文件、仓库这类通用画面，偶尔会有不太贴的空镜。
- 很小、很淡的字偶尔还会漏掉；看到了可以在「精修画面」里换掉那一镜。
- 素材主要来自 B 站 UP 主视频，商用有版权风险。
