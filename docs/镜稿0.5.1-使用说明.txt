镜稿 0.5.1（Windows 10/11 64 位）

在 0.5.0（去水印、去花字、去竖屏黑边）的基础上，按客户 10 月 27 日晚的反馈改的：

1. 速度回到 0.4.9 以前。
   0.4.9 换了大素材库以后，每组候选从十几个涨到二十多个，每个都要读预览、做水印预检，一条片子多花几分钟到十几分钟。
   现在每组候选封顶 20 个（素材库给得够就少搜 B 站），水印预检少读一半帧，新闻模式少听一点报道。
2. 更干净、更少重复。
   一个镜头没有贴题的干净画面时，依次用：同一视频别的时间段（长视频可以多取几段）→ 素材库里描述对得上的新视频
   → 相关图片做成动态画面 → 借用别的镜头的干净画面（借出次数轮着来，不再一段画面借七八次）。
   带水印、花字、竖屏的片段只在这些都没有时才用。补位画面抽检时只看干不干净，不再卡贴题。
   钞票冠号、行情图上的价格、屏幕计数器不再被误当成联系方式扔掉。
3. API Key 不再莫名失效。
   粘贴 Key 时带进的空格、换行、看不见的字符会自动去掉；保存时当场找服务商验证，不对就直接提示。
   换好 Key 后，因为 Key 失效而失败的片子自动重新排队，不用一条条点。
4. 素材库 16.7 万个视频（原来 11.2 万）。第一次打开会在后台并进去，大约 10 分钟，期间可以照常做视频。
5. 封面：没有“标题：”那一行时，用文件名标题（去掉末尾的“-标签-标签”），不再用正文第一句话；封面字只用标题里的原话，黄条只放问句。
6. 包含 0.5.0 的全部改动。

请务必：每台电脑都在 设置 → 素材搜索 → “扫码登录 B 站” 登录一次。

怎么装：解压覆盖旧版文件夹最省事（旧项目也都在）；解压到新文件夹也行，API 和 B 站登录会自动带过来。左下角显示「v0.5.1 测试版」。
