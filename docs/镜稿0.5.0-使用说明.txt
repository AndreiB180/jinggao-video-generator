镜稿 0.5.0（Windows 10/11 64 位）

这一版按客户 10 月 27 日的反馈改的，主要是素材质量：

1. 水印、大花字。
   带大花字、大段文字、去不掉水印的片段，不再直接用。
   一个镜头先找干净的视频；找不到就用相关图片做成动态画面；再不行借用别的镜头的干净画面；
   这些都没有，才用带水印的片段，带花字的排在最后。
   画面角上裁不掉的小台标、@账号名，自动按周围的画面抹掉（不打马赛克）。
   特别大的字不管在画面哪里都算花字（像表情包底下的大红字），不再当成字幕裁掉了事。
2. 竖屏和大黑边。
   竖屏视频、两边一大半是黑边或模糊色块的视频（竖屏塞在横屏里），在挑片时就丢掉，不下载；
   下载后才发现的，和带水印的片段一样排到最后。
3. 行情图、K 线图不再被误删。
   以前图上的价格、钱包地址、日期被当成“联系方式”，整段素材被扔掉（讲币安那条因此出了 24 张文字卡）；现在只认真正的电话、QQ、微信。
4. 少出模糊文字卡。
   实在没有画面时，先多借用几次已经用过的画面，最后才用文字卡。
5. 登录更稳。
   三台电脑共用一条宽带被 B 站限流时，软件确认登录那一下可能被拒，以前这条片子就当成没登录（只有 480p）；现在照样用保存的登录。
6. 不用再重填 API、重扫码。
   API Key、B站登录、远程协助识别码会在电脑的用户文件夹里另存一份；以后新版本解压到别的文件夹，打开就自动带上。
   这次第一次打开 0.5.0，会自动从旁边的旧版本文件夹里找回来（旧版和新版放在同一个文件夹下面就行）。
7. 更省 CPU。
   片段转码优先等显卡，不再挤到已经满载的 CPU 上。

请务必：每台电脑都在 设置 → 素材搜索 → “扫码登录 B 站” 登录一次（最好每台不同的号）。
没登录时 B 站大多数视频只给 480p，会被跳过，能用的素材少一大半，片子里重复和文字卡就多。

CPU 显示 100% 是正常的：那是镜稿自己在读字、分析画面、转码。同时做 3 条时每条都会慢一些，总产量差不多。

怎么装：解压覆盖旧版文件夹最省事（旧项目也都在）；解压到新文件夹也行，API 和 B 站登录会自动带过来，双击启动，左下角显示「v0.5.0 测试版」。
